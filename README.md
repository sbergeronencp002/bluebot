# Simulateur Blue-Bot 🐝

Simulateur pédagogique de programmation et de déplacements, en français, utilisable dans un navigateur.

## Fonctions
- Tapis coloré de 5 × 5 cases par défaut, ajustable.
- Séquence de programmation sous forme de tuiles à gauche.
- Parcours au centre et commandes à droite (avancer, reculer, rotations, GO, X et pause).
- Placement facile de **Départ**, **Fin** et **Obstacle**.
- Tapis de lettres, de nombres et mixtes; importation d'images et PDF.
- Sons et animations pour les collisions et la réussite.
- Sauvegarde et réouverture des projets.

## Lancer le simulateur
Ouvrir `index.html` dans un navigateur, ou accéder à GitHub Pages après son activation.

## Publier avec GitHub Pages
1. Dans **Settings → General**, vérifier que le dépôt est **Public** (sur GitHub Free, GitHub Pages pour un dépôt privé n'est généralement pas disponible).
2. Dans **Settings → Pages → Build and deployment**, sélectionner **Deploy from a branch**.
3. Sélectionner la branche `main` et le dossier `/(root)`, puis **Save**.
4. Adresse prévue : https://sbergeronencp002.github.io/bluebot/

L'importation d'images fonctionne hors ligne; l'importation de PDF nécessite le chargement de PDF.js par Internet.

## Mise à jour
Modifier `index.html` sur `main` pour publier automatiquement une nouvelle version via GitHub Pages.
